# Dokumentasi Kegiatan - Day 1 Proyek Workshop

## 1. Prompt Engineering & AI Building
Pada sesi awal workshop, kami mempelajari cara merancang instruksi (*prompt*) yang efektif kepada AI agar menghasilkan kode aplikasi yang akurat dan terstruktur dengan menerapkan struktur yang baik:
* **Role:** Menentukan peran AI (contoh: *You are helping me build a beginner-friendly student task planner as a simple web application*)[cite: 9, 10].
* **Task:** Menjelaskan tujuan utama pembuatan aplikasi[cite: 9, 10].
* **Context & Constraints:** Membatasi teknologi yang digunakan (HTML, CSS, dan vanilla JavaScript tanpa dependensi rumit)[cite: 10].
* **Format:** Meminta kode lengkap beserta cara menjalankan dan menguji aplikasinya[cite: 10].

## 2. Rangkuman Materi Git & GitHub
* **Git vs GitHub:** 
  * **Git:** *Distributed Version Control System* (DVCS) untuk melacak perubahan kode secara lokal di komputer[cite: 16].
  * **GitHub:** Platform berbasis web untuk menyimpan *repository* Git secara online dan mendukung kolaborasi tim[cite: 16].
* **Essential Git Commands yang Dipelajari:**
  * `git init` : Memulai repository baru di direktori lokal[cite: 18].
  * `git add .` atau `git add -A` : Memindahkan file yang diubah ke *staging area*[cite: 18, 22].
  * `git commit -m "pesan commit"` : Menyimpan perubahan ke dalam *repository* lokal[cite: 14, 18].
  * `git push origin main` : Mengunggah kode dari *repository* lokal ke GitHub[cite: 19].
